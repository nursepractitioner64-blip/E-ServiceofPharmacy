รับข้อมูลจาก E-StockScan

เมื่อสแกนจาก E-StockScan ให้ระบบต้นทางส่งค่าที่วัดได้มายัง API นี้ ระบบจะนำข้อมูลมาแสดงในรายงานเดือนเดียวกันโดยอัตโนมัติ

POST /api/temperature-check/records

ข้อมูลที่ต้องส่ง: date, time (09:00 หรือ 16:00), type (freezer / fridge / room / humidity), value และส่ง source: "E-StockScan"

ตัวอย่าง JSON
{"date":"2026-10-29","time":"09:00","type":"fridge","value":5.2,"source":"E-StockScan"}
